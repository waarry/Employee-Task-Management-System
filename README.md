# Employee Task Management System

Java Swing desktop application with MySQL 8 for managing employees and tasks.

**Status:** Phase 1 complete (project structure, Maven, database schema).

## Quick start
1. Install JDK 21, MySQL 8, IntelliJ IDEA.
2. Edit the password in `database/schema.sql` (replace `CHANGE_ME`), then run it.
3. Copy `src/main/resources/application.properties.example` to
   `application.properties` and fill in your database password.
4. Open the project in IntelliJ and run `com.employee.Main`.

Full setup guide, report and viva material are added in later phases.
